# Bopper Weather App

## Описание проекта

Это интерактивное веб приложение для отслеживания текущей погоды в разных городах мира. Пользователь может найти город по названию и при нажатии на кнопку search карточка города с погодными данными отобразится на экране и автоматически сохранится используя localStorage браузера. В проекте реализованы также кнопки для удаления одного города (крестик на карточке) или для удаления всех городов (красная кнопка снизу, которая появляется при добавлении как минимум одного города). Один и тот же город не может быть добавлен два раза, сделана защита от этого. Все кнопки интерактивны, проект без проблем запускается

## Стек технологий

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS, ES6+, `async/await`, `Promise.all`)
* **Backend:** Обращение к стороннему REST API (OpenWeatherMap API)
* **База данных:** Локальное хранилище браузера (`localStorage`)

## Как запустить локально

Склонируйте данный репозиторий:

```
git clone <ссылка на репозиторий>
```

Далее перейдите в директорию проекта:

```
cd <директория проекта>
```

Далее откройте файл index.html в браузере. Для удобства можете использовать LiveServer
